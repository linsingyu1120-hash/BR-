# <BR雷神大摆锤>

## 模块简介
BR雷神大摆锤是BR用于取、放、翻转天空块的爪子。摆锤安装在二级升降机构之上，可以进行升降，也可以旋转收进/翻出BR。摆锤自身可以俯仰（摆锤可以俯90°，暂时不需要仰），以及沿垂直地面的平面方向进行360°旋转。

## 文件说明
- `APL/` - 用户自定义扩展功能，在此目录下新建子目录并添加功能模块
- `Core/` - cubemx生成的源码，禁止添加新的文件
- `DOCS/` - 模板工程相关文档
- `FML/` - 功能模块库，包含了常用的零碎功能模块，按需补充
- `HDL/` - 板级外设驱动，包含灯和蜂鸣
- `IRQ/` - 中断服务函数，包含了中断回调函数重定义
- `Motor/` - 电机驱动，目前仅添加了z和dji
